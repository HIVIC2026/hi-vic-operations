// ELECTRICIAN test cases (TEST electrician business owner, e.g. qa.rec.delta@hivic-test.example).
// One case = the "### " title line, then its steps down to the next "### ".
//   Title  -> testRigor "Test case description" (leave out the ###).
//   Steps  -> testRigor "Custom steps".
// Tags:
//   [read-only]                 looks only. Safe to run any time, in any order.
//   [CHANGES THE TEST JOB]      moves the TEST job on. Run in the order shown, after the read-only ones.
//   [CHANGES THE TEST BUSINESS] changes the TEST electrician business records.
//   [ONE-WAY - run last]        can't be undone from the screen.
// "// Needs:" says what state the TEST job must be in first. If it isn't, the case fails at its first check. That's expected.
// Words that change (suburbs, dates, amounts) use part of the text only. testRigor matches part of a label.
// Day tiles and time menus change every day. Those steps pick "the 1st / 2nd / 3rd" one. If testRigor marks one red,
// open the step in its editor and pick the tile it offers.
// Rules used: sign in as electrician, sign out of trade, open test job as electrician (see rules.txt).
