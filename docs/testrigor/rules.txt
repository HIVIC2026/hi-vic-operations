### RULE: open sign in
// The staff address opens sign-in at /auth. The bare address on this host also redirects to /auth (decision 381).
open url "https://portal.homeinsulationvictoria.com.au/auth"
check that page contains "Staff & trade portal"
check that page contains "Welcome back."


### RULE: sign in as installer
open sign in
enter stored value "installerEmail" into "Email"
enter stored value "installerPassword" into "Password"
click "Sign in"
// Installers land on My work (/field).
check that page contains "My work"
check that page contains "Coming up"
check that url contains "/field"

### RULE: owner code check
// Signing on the owner link asks for a 6-digit code. On a TEST job nothing is sent:
// the page shows "TEST job, nothing is sent. Your code: 123456". We copy that code.
check that page contains "Let's check it's you"
click "Email me a code"
check that page contains "TEST job, nothing is sent."
extract value by regex "[0-9]{6}" from "Your code:" and save it as "ownerCode"
enter stored value "ownerCode" into "Enter code"
click "Check my code"
check that page does not contain "Let's check it's you"


### RULE: open test role tab
// Office only. Opens a one-time TEST sign-in for this TEST job in a second tab, with no password.
// Use it when a TEST installer or electrician password is not set yet.
// Before calling: click "Open as installer boss" (or "Open as electrician" / "Open as owner" / "Open as worker").
check that page contains "Open TEST"
click "Open TEST"
switch to tab "2"
check that page does not contain "Welcome back."
