// OFFICE test cases (TEST office account admin@hivic.test).
// One case = the "### " title line, then its steps down to the next "### ".
//   Title  -> testRigor "Test case description" (leave out the ###).
//   Steps  -> testRigor "Custom steps".
// Tags:
//   [read-only]              looks only. Safe to run any time, in any order.
//   [CHANGES THE TEST JOB]   moves the TEST job on. Run in the order shown, after the read-only ones.
//   [CREATES TEST DATA]      adds a new TEST record.
//   [ONE-WAY - run last]     can't be undone from the screen.
// The office account sees REAL customers too. These cases only ever change the TEST job (stored value testJobNumber)
// or records marked TEST. Never point a state-changing case at a real job.
// Never automate: Settings > Switches, Communications > "Cancel these", Money > "Mark paid", Partners approvals of
// real applicants, "Publish new prices". They change live behaviour or real money. See coverage.md.
// Rules used: open sign in, sign in as office, sign out of office, open test job as office, open test roles dialog,
// open test role tab (see rules.txt).
