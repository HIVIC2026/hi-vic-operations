// HOMEOWNER test cases. Homeowners don't sign in: they use the public calculator and their secure My job link.
// One case = the "### " title line, then its steps down to the next "### ".
//   Title  -> testRigor "Test case description" (leave out the ###).
//   Steps  -> testRigor "Custom steps".
// Tags:
//   [read-only]              looks only. Safe to run any time, in any order.
//   [CHANGES THE TEST JOB]   moves the TEST job on. Run in the order shown, after the read-only ones.
//   [ONE-WAY - run last]     can't be undone from the screen.
// "// Needs:" says what state the TEST job must be in first. If it isn't, the case fails at its first check. That's expected.
// Calculator: on the staff address portal.homeinsulationvictoria.com.au the bare "/" opens staff sign-in (decision 381),
// so the calculator cases use "/calculator" there. The customer address estimate.homeinsulationvictoria.com.au serves
// the same calculator at "/". Both are checked below.
// The calculator's "Register my interest" form is only checked for its error messages. It is never sent from here,
// because a sent form makes a REAL enquiry on the live portal.
// Owner link cases use stored value "ownerJobLink": the TEST job's link, ending /my-job/<code>. Never paste it in a file.
// Rules used: open test job as owner, owner code check (see rules.txt).
