Jo, 6 Oct 2026: EVERY form an owner or landlord signs is e-signed in the portal with the one signing screen (texted/emailed 6-digit code + ticks + typed full name). No paper, no wet signatures, no outside e-sign service.
Covers Step A consents, landlord consent, Step B agreement + rights + VEEC assignment, Step C ESC consent + PIESA-copy acknowledgement, Step D reconfirm, and any owner declaration on the official VEEC assignment form or PIESA/PIISA forms (if Mitti asks the owner to sign, capture it in the portal and attach it).
Each signature produces a signed PDF of that exact form (wording, version, ticks, typed name, date/time, code destination, IP), saved in the job file and emailed to the owner (queued while sending is off).
