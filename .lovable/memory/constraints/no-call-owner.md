Standing rule from Jo (5 Oct 2026), all owner-facing screens, emails and SMS:
- No HIV phone number anywhere; no "Call us" / "Questions? Call us".
- Use "Got a question? Message us" which opens the in-portal message thread.
- The only call button an owner sees is to call their booked trade, on the visit card.
- Applies to owner pages, quote pages, campaign emails and reminders.
- Public fallback (no job/thread yet, e.g. save errors): point to the website contact page, never a phone number.
- The locked likely-estimate email keeps its website "Contact us" link (hash-locked); it has no phone prompt — revisit only if Jo asks.
