Preview only. Use one shared component on all three trade job-day pages.

Pre-start section:
1. Navy card "Sharp photos and videos, every time" with the exact approved explanation, pink regulator/rebate warning, four tips (Wipe the lens; Torch on, not flash; Hold still, tap to focus; Move slowly in videos), and pink retake line.
2. "Phone check (n/3)" checklist: Location on for Mitti; Battery over 50%; Mitti open on this job. Remember checks per job.
3. "How to turn on location for Mitti" with the approved six iPhone steps, five Android steps, and "You only need to do this once per phone."
4. Green lightning Start button stays disabled and reads "Tick all 3 to start" until all three checks are ticked. Enabled labels: Start check / Start Ready Check / Start install.

Install day:
- Navy card: "Install today · {time}", "Install · {owner}", address, Directions / Call owner.
- Start opens the Mitti install form containing PIISA, photos and bag labels.
- Synced complete state: "That's a wrap. Done and dusted. We'll check the photos and sign it off."
- Missing state: "Nearly there. {N} photos missing." and list missing items.
- No step-by-step list on the page.

Ready Check retains "Couldn't get in?".
